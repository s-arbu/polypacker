# PolyPacker

PolyPacker generates an Arcade config from an asset prompt with Gemini, then
selects a pre-made demo model from the local `public/` assets based on prompt
keywords. The browser packages the model and `arcade-config.json` into a ZIP.
The model step includes a short simulated delay for the hackathon demo; models
are bundled assets, not generated by an API.

## Local development

1. Create `.env.local` in the project root:

   ```env
   GEMINI_API_KEY=your_gemini_api_key
   ```

   Keep this server-only variable as `GEMINI_API_KEY`; do not prefix it with
   `VITE_`. `.env.local` is ignored by Git.
2. Install dependencies and start Vite:

   ```sh
   bun install
   bun run dev
   ```

The Nitro Gemini route and Vite app run together in the same dev server. Gemini
validates the config before the local demo model is selected. Prompts are
limited to 500 characters.

The local model selector uses case-insensitive whole words. `green`, `sticks`,
or `panda` selects `bamboo.glb`; otherwise `cute`, `animal`, or `zoo` selects
`capybara.glb`; all other prompts select `retro_tv.glb`. Bamboo keywords take
priority if a prompt matches both groups.

## Deployment

The Vite + Nitro setup can deploy to Vercel. Import the repository and add
`GEMINI_API_KEY` under the project's Environment Variables, then deploy. Do not
add the key to frontend build variables or source control.

The Gemini generation endpoint is public and unauthenticated, so anyone who can
reach it can use the Gemini project's quota. Configure and monitor the Gemini
project's quota.

Google's Gemini Free Tier has usage limits and may use submitted prompts and
outputs to improve its products. The Interactions API retains data for one day
by default on the Free Tier. Do not submit sensitive information.
