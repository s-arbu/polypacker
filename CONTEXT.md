# PolyPacker

PolyPacker helps game developers turn an asset description into a bundle containing a 3D asset and the Arcade metadata needed to use it.

## Language

**Asset bundle**:
A downloadable package pairing a 3D asset with the Arcade config needed by the Arcade engine.
_Avoid_: Raw model

**Arcade config**:
JSON metadata that describes an asset's gameplay properties for the Arcade engine.
_Avoid_: Model settings

**Demo model**:
A pre-made 3D asset selected to represent the result of a prompt-driven model-generation step in the hackathon demo.

**Generated model**:
A 3D model created by a 3D-generation service from the user's asset prompt.
